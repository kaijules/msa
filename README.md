# Spark Music

Ứng dụng nghe nhạc (HTML/Bootstrap 5/JS thuần) chuyển từ template Spark Admin, giữ nguyên giao diện.

- `index.html` Khám phá · `tables-basic.html` Bài hát · `ui-forms.html` Tải lên & Playlist · `page-login.html` Đăng nhập
- Logic phát nhạc: `music.js` (thanh player ở cuối trang, yêu thích/playlist lưu bằng localStorage)
- Nhạc demo stream từ SoundHelix (cần internet). Bài tải lên chỉ tồn tại trong phiên.

Giao diện gốc: Spark Admin (MIT) — Spark Admin Dev / ThemeWagon.
